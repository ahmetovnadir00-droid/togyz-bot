# Тоғызқұмалақ — бот на нейросети

Всё приложение в одном файле `index.html`: доска, бот, задачи, разбор партий. Сервер ничего не считает — бот работает в браузере.

Запуск на Railway: `Procfile` поднимает простой веб-сервер (`python -m http.server $PORT`).
Локально: открыть `index.html` в браузере.
